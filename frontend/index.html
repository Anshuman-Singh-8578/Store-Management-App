About this project

This is a full-stack retail management system built to solve a real problem: small shop owners often have no easy way to see what's actually selling, when to reorder, or how to run a modern checkout without expensive POS hardware.

Under the hood, it combines a SQL-backed inventory and transaction system with atomic billing (so a sale is never left half-recorded), server-side discount logic, and item-level demand analytics — all served through a FastAPI backend and a custom frontend, deployed on real cloud infrastructure.

Billing and stock changes are protected behind login, so only authorized accounts can modify data, while sales insights remain viewable for anyone exploring the demo.
